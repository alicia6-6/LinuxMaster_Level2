# 리눅스마스터 2급 암기장 (웹 버전)

Flutter 앱(`linux_master2/`)과 같은 문제 은행을 브라우저에서 그대로 풀어볼 수 있는
빌드 도구 없는 정적(static) 웹 버전입니다. 카테고리별 학습, 전체 학습, 오답노트,
즐겨찾기, 정답/오답 채점과 해설 보기, 학습 기록(로컬 저장)까지 앱과 동일하게 동작합니다.

## 실행 방법

가장 간단한 방법: `index.html`을 더블클릭해서 브라우저로 바로 열면 됩니다.

로컬 서버로 열고 싶다면 (권장, 일부 브라우저의 file:// 제한을 피할 수 있음):

```bash
cd linux_master2_web
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 폴더 구조

- `index.html` — 진입점
- `css/styles.css` — 스타일 (라이트/다크 테마 포함)
- `js/app.js` — 전체 로직 (홈/퀴즈/결과 화면, 채점, localStorage 저장)
- `js/data.js` — 문제 데이터 (자동 생성 파일, 직접 수정하지 마세요)

## 문제 데이터 갱신

문제 데이터의 원본은 `linux_master2/assets/data/questions.json`입니다. 그 파일을
수정한 뒤에는 저장소 루트에서 아래 스크립트를 실행해 웹 버전 데이터를 동기화하세요:

```bash
python scripts/sync_web_data.py
```

## 참고

- 학습 기록(정답/오답/즐겨찾기)은 브라우저의 `localStorage`에 저장됩니다. 시크릿 모드나
  기기를 바꾸면 기록이 초기화됩니다 — 앱의 `SharedPreferences` 저장과 동일한 방식(로컬 전용)입니다.
  Flutter 앱과 웹 버전은 서로 다른 저장소를 사용하므로 학습 기록이 자동으로 동기화되지는 않습니다.
- 별도 서버나 빌드 과정 없이 정적 파일만으로 동작하도록 만들어졌습니다.
