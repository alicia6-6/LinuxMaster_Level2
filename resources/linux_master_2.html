1. 다음 중 리눅스 기본 디렉터리에 대한 설명으로 틀린 것은?

①/bin에는 기본 실행파일들, 즉 사용자 명령어들이 있다.
②/etc에는 시스템 관리시 필요한 설정파일들이 있다.
③/opt에는 각 장치에 필요한 socket 및 log파일들이 있다.
④/proc에는 시스템 관리를 목적으로 메모리상에 만들어 놓은 가상 디렉터리로서, 디렉터리내의 파일들은 현재 시스템 설정을 보여준다.


▶해설
/opt
응용프로그램 설치를 위한 폴더

Add-On (응용)소프트웨어 패키지가 설치됩니다. 레드햇 리눅스는 이 디렉토리를 구성하지 않습니다. 패키지 매니저가 설치와 삭제를 수행.

대부분의 로그 파일은 /var/log 파일에 저장됩니다.

리눅스 디렉터리


/dev [Device : 장치] – 마운트 지점을 제공
시스템에 장착되어 있는 주변 장치(마우스, 키보드, 모니터,그래픽카드, CD롬, 하드디스크 등)을 파일로 처리하여 저장하고 있습니다.(드라이버)


/etc [Etcetera : 기타, 여러가지, 잡동사니]
시스템 설정 파일이 들어 있는 폴더 입니다.
사용자 정보를 가지고 있는 passwd (/etc/shadow에 저장됨), 그룹정의 파일인 group, 프린터 목록파일 printcap, 자동으로 마운트 되는 파일 시스템을 등록해 두는 파일 시스템 테이블 fstab, 각종 네트워크관련 파일과 기본적인 시스템 환경 결정 파일들이 있습니다.


/bin [Binary : 2진법의] – 외부명령어 위치( 명령어 실행 전에 fork(서브프로세스)가 실행됨.)
(/bin/bash) 기본적인 파일처리 명령, 텍스트 처리 명령, 네트워크 처리 명령 등 여러 가지의 명령어들이 실행 파일의 형태로 저장되어 있습니다. 이 안에 있는 명령어들은 어떠한 경로에 있던지 실행되게 되어 있으므로 꼭 이 경로로 와서 실행할 필요는 없습니다.


/lib [Library : 도서관, 서재등]
시스템과 응용프로그램에서 사용하는 대부분의 라이브러리가 들어 있는 디렉터리 입니다.
이 폴더는 중요한 부분이므로 임의 조작을 하지 않는 것이 좋습니다.


/home
사용자 계정을 만들면 사용자 계정의 이름과 동일한 디렉터리가  /home 디렉터리 아래에 만들어 집니다.
이 디렉터리는 사용자 계정마다 기본적으로 제공되는 것으로, 새로 등록한 사용자는 이 디렉터리 안에서만 컴퓨터를 사용할 수 있습니다.
다른 디렉터리의 이동 시 허가 받지 않은 경로는 이용이 제한됩니다.
허가와 금지는 “시스템 관리자”가 지정할 수 있습니다.
개인용 공간으로 이해 하시면 되겠습니다.


/root
이곳은 root 사용자만 사용이 가능합니다.
일반 사용자들의 출입이 엄격하게 금지되어 있는 공간입니다.


/proc [Process]
커널과 프로세스를 위한 가상 파일 시스템 디렉터리, ‘가상파일시스템’에 메모리에 존재하는 작업들이 파일 형태로 존재함.
이 디렉터리는 시스템의 CPU정보가 있는 cpuinfo파일과 사용중인 인터럽트 목록과 인터럽트 발생 번호가 나오는 interrupts파일, 사용중인 I/o주소 목록을 확인하는 ioports파일, PCI BIOS정보를 보여주는 pci파일, 시스템 통계를 보여주는 stat파일 등이 있습니다.


/boot
리눅스 계열에서 OS 부팅에 사용되는 파일을 담는 폴더, GRUB[부트로더), lost+found [fsck등에서 발견된 결함이 있는 파일에 대한 정보를 보관]


/sbin [System Binary]
파일 시스템 처리 명령, 네트워크 인터페이스 설정 명령, 시스템 초기화 명령, 커널 모듈의 관리 명령 등 시스템의 전반적인 관리 명령어들이 있는 디렉터리 입니다.
이 디렉터리 파일의 사용은 root 계정 에게만 허가되어 있습니다.


/tmp [Temporary : 일시적인, 임시](기본적으로 Sticky-bit가 설정됨)
어떤 작업을 위해서 임시로 파일을 생성하는 공간입니다.
주로 사용자들의 프로그램에서 임시로 읽어 들여야 하는 입,출력 파일들을 저장하는 곳입니다.


/var [Variable Data]
시스템을 가동하면서 생기는 각종 임시 파일을 저장하는 디렉터리 입니다.(/var/log 대부분의 로그파일, 전자 메일, 프린트 관련 파일 저장)
커널 메시지를 기록하는 파일, 그리고 각종 스풀링이 필요한 파일들
*스풀링은 프린터 인쇄 명령 시 프린터와 CPU간 속도 차이를 극복하고자 생긴 기능으로 CPU에서 일정 저장공간에 인쇄할 목록을 쌓아두고 프린터는 해당 목록의 인쇄를 순서대로 진행하는 것을 말합니다.


/usr[Universal System Resources]
시스템, 응용프로그램에서 필요한 파일들이 저장되어 있는 디렉터리입니다.
설치 할 때 하드디스크에서 가장 많은 용량을 지정해 주어야 하는 디렉터리 입니다.


/opt [OPeraTion]
Add-On (응용)소프트웨어 패키지가 설치됩니다. 레드햇 리눅스는 이 디렉터리를 구성하지 않습니다.
패키지 매니저가 설치와 삭제를 수행.


/lost+found
파일 시스템 복구를 위한 fsck의 링크 디렉터리

2. 다음 중 콘솔 모드나 터미널 창에서 로그아웃하는 방법으로 틀린 것은?
①logout
②exit
③[Ctrl]+[c]
④[Ctrl]+[d]


▶해설
Ctrl + c는 로그아웃이 되지 않습니다.
로그아웃과 정상적인 시스템 종료는 차이가 있습니다.
정상적인 종료를 말 그대로 리눅스 시스템을 종료한다는 의미 즉 전원이 off 됨을 의미하구요.

리눅스 시스템은 ON 되어 있는 상태에서 현 사용자만 로그아웃(연결종료)을 한다는 의미입니다.
logout, exit, Ctrl + d는 모두 로그아웃과 같은 결과를 냅니다.


ctrl + c는 주로 리눅스 명령어를 실행하다 "중지"시킬 때 사용합니다.

프로세스 시그널에서 SIGINT 즉 Interrupt신호(현재 실행 중인 프로그램을 중지)에 사용됩니다.

3-1. 다음 중 man 명령 실행과 가장 관계가 깊은 명령어로 알맞은 것은?

①cat

②more
③less
④which


▶해설

man, cat, more, less는 문서 파일의 내용을 읽을 때 사용하는 명령어들 입니다.

man과 less는 페이지 단위로 내용을 확인 해 볼 수 있습니다.

그리고 man과 less는 이미 지나간 페이지도 다시 돌아와서 볼 수 있습니다.

페이지 단위 출력이지만 한 줄씩 내용을 살펴 볼 수도 있습니다.


which 명령어는 특정 명령어의 위치를 찾아주는 명령어입니다.

‘which [명령어]’와 같은 방식으로 사용됩니다.
예)which find → /usr/bin/find


more : 파일을 읽어 화면에 화면 단위로 끊어서 출력하는 명령어

cat : 파일의 내용을 한 번에 모든내용을 출력


less : 파일을 읽어 화면에 출력하는 명령어

more는 파일의 위에서 아래 방향으로만 출력 됩니다.

그렇기 때문에 지나간 내용을 다시 볼 수 없습니다.

반면 less는 한 번에 보여지는 만큼만 읽어서 출력하기 때문에 대용량의 파일을 열어 볼 때 빠르게 사용 할 수 있습니다.(man도 사용법이 유사합니다.)

5. 다음 설명에 해당하는 명령으로 알맞은 것은?
하나의 파일을 여러 개의 작은 파일로 분리하는 명령으로 옵션을 지정하지 않고 실행하면 1000줄 단위로 파일을 분리한다.


①cut
②sort
③split
④wc


▶해설
cut : 각 줄마다 필요한 부분만 잘라내어 반환해주는 명령어

옵션
-d: 구분자 설정(기본적으로 구분자를 tab 문자로 사용)
-f: 추출할 위치 또는 구간 설정


sort : 숫자순, 알파벳 순으로 정렬해주는 명령어

옵션
-r: 내림차순 정렬(기본적으로 오름차순)
-t: 구분자 지정
-k: 정렬할 열 지정
-n: 숫자로 해석해서 값의 크기로 정렬
-b: 포함된 공백 무시


split : 큰 파일을 여러 작은 파일로 나눌때 사용하는 명령어
옵션없이 사용하면 분할파일 뒤에 영문 2자리가 추가되어 구분됨.(파일명_aa,파일명_ab, 파일명_ac)
분할 기준은 하나의 파일이 1,000라인으로 분할


옵션
-b : 분할 기준으로 바이트 단위로 지정
-c : 라인을 기준으로 지정 다만 뒤에 바이트를 함께 사용하여 제한
-l : 순수하게 라인수를 기준으로 파일분할
-n : 파일을 균등하게 분할
-d : 분할되는 파일의 뒤에 영문이 아닌 숫자로 지정(0부터시작)
-a : 분할되는 파일의 뒤에 영문개수로 지정(aaa, aab,aac순)


wc : 파일의 단어,문자, 라인 수를 세어주는 명령어
사용법 : wc[옵션][파일명]

-c : 문자 수만
-m : 캐릭터 수만
-l : 라인(줄) 수만
-w :  단어 수만

watch는 원하는 명령어의 결과를 원하는 시간에 맞게 주기적으로 리프레시(새로고침) 하여 결과를 보여주는 명령어입니다. 시스템의 자원 사용량을 모니터링 하거나, 특정 명령어를 반복적으로 입력해서 결과를 확인해야 할 때, 유용하게 사용할 수 있는 명령어 입니다.

-n 옵션은 입력한 명령어의 결과를 원하는 초 단위로 출력해 주는 기능(기본 값: 2초)
사용 예) watch -d -n 10 명령어 → 명령어를 10초마다 실행하라는 의미

보통 문서의 내용을 보는 것은 cat 명령어를 이용해서 보게 되지만 프로그램 안에 있는 문자열은 strings를 이용하는 것이 보통입니다.(물론 cat으로는 프로그램 파일의 내용 확인은 안 됩니다.)


기본적인 사용방법은 아래와 같습니다.
strings <옵션> <파일명>

사용 예) strings anaconda-ks.cfg → 아래에 해당 내용들이 출력됨.


rdate(remote date)는 원격지의 타임서버에서 시간 정보를 가져와서 로컬 시스템의 시간과 동기화를 하는 명령어입니다.


기본적인 사용방법은 아래와 같습니다.
rdate [옵션]... [타임서버 주소]
사용 예) rdate -p time.bora.net

여러 개의 디스크를 필요에 따라 용량을 나눠서 사용하는 방법으로는 RAID와 LVM이 있습니다.


RAID (= 동적디스크)

RAID(Redundant Array of Independent Disks 혹은 Redundant Array of Inexpensive Disks)는 여러 개의 하드 디스크에 일부 중복된 데이터를 나눠서 저장하는 기술입니다. 복수 배열 독립 디스크로도 부릅니다.

RAID는 하드웨어 레이드와 소프트웨어 레이드로 나뉘는데 하드웨어는 컨트롤을 역할을 수행하는 하드웨어를 별도로 사용하는 것이고, 소프트웨어 레이드는 컨트롤을 소프트웨어로 하는 것을 말합니다.


LVM(Logical Volume Manager)는 여러 개의 하드디스크를 합쳐서 한 개의 파일시스템으로 사용하는 것으로 필요에 따라 나누어 사용할 수 있습니다.

LVM구성 순서 : PV(Physical Volume) → VG(Volume Group) → LV(Logical Volume)10G, 20G디스크 → 2개를 하나로(30G) → 하나의 디스크처럼 다시 나눠서 사용(15G, 15G)

LVM은 사용 중인 볼륨 파티션이 데이터 이전 없이도 확장하거나 축소할 수 있습니다.

Physical Volume(LVM)을 사용하여 디스크 오류가 발생하더라도 다른 디스크를 통해 계속 동작하게 설정할 수 있습니다.
